# ☁️ Cloud-Based Attendance Management System

A web-based Attendance Management System developed using **Django** that allows administrators to manage students, subjects, departments, and attendance records efficiently. The project is deployed on **Render** for public access.

## 🚀 Features
- Secure Admin Login
- Student Management
- Department Management
- Subject Management
- Attendance Marking
- Attendance Reports
- Dashboard with Statistics
- Responsive User Interface
- Cloud Deployment using Render

## 🛠️ Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- Render
- Git & GitHub

## 📂 Modules
- Authentication
- Dashboard
- Student Management
- Subject Management
- Department Management
- Attendance Management
- Reports

## 📌 Project Workflow
1. Login to the system.
2. Add Departments and Subjects.
3. Register Students.
4. Mark Attendance.
5. View and Manage Attendance Reports.

## 🌐 Deployment
The project is deployed on **Render**
